# Atividade Prática: HTML e CSS

## Monte sua primeira página: "Sobre Mim"

> Material educacional — Atividade de Introdução ao HTML e CSS

---

## Objetivo

Criar uma página **"Sobre Mim"** do zero, usando apenas **HTML** e **CSS**. O tema é livre: pode incluir aspectos profissionais, educacionais ou pessoais.

> **Importante:** o foco é *praticar os elementos aprendidos*, não precisa ficar perfeito. Experimente, erre e teste no navegador!

---

## Requisitos obrigatórios

Sua página precisa conter **todos** os itens abaixo:

- A estrutura básica completa (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`).
- Um `<title>` adequado e o `<meta charset="UTF-8">`.
- Pelo menos **um título** `<h1>` e um `<h2>`.
- No mínimo **dois parágrafos** `<p>`, usando `<strong>` e `<em>` em alguma parte.
- Pelo menos **um link** `<a>` para um site externo.
- Um **arquivo CSS externo** conectado com `<link>`.
- Criar uma paleta de cores e aplicá-la no CSS.
- Usar **pelo menos uma classe** (`class`) e estilizá-la.
- Aplicar `padding`, `margin` e `border` em algum elemento (box model).

---

## Passo a passo sugerido

1. Crie uma pasta chamada `sobre-mim`.
2. Dentro dela, crie dois arquivos: `index.html` e `estilo.css`.
3. No HTML, monte primeiro a estrutura básica e conecte o CSS no `<head>`.
4. Adicione o conteúdo: título, foto, parágrafos de apresentação e a lista.
5. Abra o arquivo no navegador para ver como está (clique duplo no `index.html`).
6. Agora vá para o `estilo.css` e comece a estilizar: fundo, fontes, cores.
7. Ajuste espaçamentos com `padding` e `margin` até ficar agradável.
8. Salve e recarregue o navegador a cada mudança para acompanhar o resultado.

---

## Versionamento

Crie um repositório no GitHub com o mesmo nome da pasta do seu projeto e envie os arquivos.

Sequência sugerida:
- Crie o repositório no GitHub.
- Siga as instruções para criar o repositório localmente.
- Adicione os arquivos do projeto.
- Faça o commit das alterações.
- Faça o push para enviar os arquivos para o GitHub.
